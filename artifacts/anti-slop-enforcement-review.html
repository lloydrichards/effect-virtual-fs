Representative diffs

Exact Effect refactor — enforce

- Effect.catchIf(e =>
    e.reason._tag === "SocketCloseError",
    () => Effect.void)
+ Effect.catchReason(
    "SocketError", "SocketCloseError",
    () => Effect.void)

Same runtime behavior. Unmatched socket reasons still fail. The callback is more precisely typed.

Unsafe cast — require evidence

if (!hasOwnProperty.call(cases, value)) throw ...
+ // SAFETY: The own-property check proves
+ // value selects a member of cases.
return cases[value] as A[keyof A]

No behavior change. The comment records the fact TypeScript cannot infer.

Factory import — do not enforce

- import { makeExport } from "./internal/export.js"
+ import { makeExport as createExport } from ...

The mechanical escape changes no architecture and makes naming inconsistent. The rule does not detect actual Effect services.

Optional property — review only

- { sequence, status,
-   ...(body === undefined ? {} : { body }) }
+ body === undefined
+   ? { sequence, status }
+   : { sequence, status, body }

Semantics stay exact, but fields are duplicated. Future replay metadata can drift between branches.

Typed union — do not enforce

- if (typeof value === "string") ...
+ // Schema or Match adds ceremony to a declared union.

Removing the check weakens runtime defense; replacing it adds machinery without improving the contract.

Public Shape type — do not rename

- export interface CheckpointStoreShape { ... }
+ export interface CheckpointStoreService { ... }

Runtime is unchanged, but the exported rename is breaking and needs a changeset and migration guidance.

What this buys you

Higher signal

Errors correspond to a concrete improvement: an exact Effect API, an explicit safety proof, a named contract, or stable formatting.

Lower migration risk

No forced public rename, weakened unknown boundary, fake service architecture, or duplicated protocol object merely to satisfy syntax.

Preserved judgment

Direct tag checks, Match, schemas, predicates, and constructors remain tools chosen for the local problem.

A path upstream

Disabled rules can return when constructor-aware, service-aware, tagged-union-aware, or scoped by source versus tests.

Method: three read-only reviewers split Effect/tag rules, type-safety rules, and architecture/style rules. The implemented policy includes executable valid and invalid fixtures. Production enforcement remains on; only two test-specific rules are disabled.
