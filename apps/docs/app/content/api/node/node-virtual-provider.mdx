# NodeVirtualProvider.ts overview

Direct Node 26.11.1 VirtualProvider binding. Construction never mounts a filesystem.

Since v0.1.0

---

## constructors

### bind

Binds a qualified volume for this scope. Does not mount or install global hooks.

**Example**

```ts
import * as NodeVirtualProvider from "@effect-vfs/node/NodeVirtualProvider"
import * as Vfs from "@effect-vfs/core/VirtualFileSystem"
import * as Effect from "effect/Effect"

const readThroughNode = Effect.scoped(
  Effect.gen(function* () {
    const volume = yield* Vfs.make({ execution: "sync" })
    const provider = yield* NodeVirtualProvider.bind(volume, { readonly: true })
    return provider.statSync("/").isDirectory()
  })
)
```

**Signature**

```ts
declare const bind: (
  volume: Volume,
  options?: {
    readonly readonly?: boolean
    readonly caller?: {
      readonly identity?: {
        readonly uid: number
        readonly gid: number
        readonly groups: ReadonlyArray<number>
        readonly privileged: boolean
      }
      readonly umask?: number
    }
  }
) => Effect.Effect<Provider, FsFailure, Scope.Scope>
```

[Source](https://github.com/lloydrichards/effect-virtual-fs/blob/main/packages/node/src/NodeVirtualProvider.ts#L431)

### Provider (class)

A provider over an existing synchronous volume. Node allocates numeric descriptors above this protocol.
Instances are constructed with bind and remain valid for its enclosing Effect scope.

**Signature**

```ts
declare class Provider { constructor(private readonly binding: Adapter.Binding, private readonly readOnly = false) }
```

  readonly readonly: Schema.optionalKey<Schema.Boolean>

          readonly uid: Schema.Natural
          readonly gid: Schema.Natural
          readonly groups: Schema.$Array<Schema.Natural>

        }>
      >
      readonly umask: Schema.optionalKey<Schema.Natural>

  >
