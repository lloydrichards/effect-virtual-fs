# Volume overview

Volume identity brands and schemas: durability, identity tokens, construction
options, and the change summaries an overlay volume reports.

Added in v0.6.0

---

## models

### OverlayChange (type alias)

One summarised change between an overlay and its base.

**Signature**

```ts
export type OverlayChange =
  | {
      readonly _tag: "Added"
      readonly path: BytePath
      readonly kind: "directory" | "file" | "symlink"
    }
  | {
      readonly _tag: "Removed"
      readonly path: BytePath
      readonly kind: "directory" | "file" | "symlink"
    }
  | {
      readonly _tag: "Replaced"
      readonly path: BytePath
      readonly beforeKind: "directory" | "file" | "symlink"
      readonly afterKind: "directory" | "file" | "symlink"
      readonly differences: readonly (
        "uid" | "gid" | "mode" | "atimeNs" | "mtimeNs" | "ctimeNs" | "birthtimeNs" | "content"
      )[]
    }
  | {
      readonly _tag: "Renamed"
      readonly from: BytePath
      readonly to: BytePath
      readonly kind: "directory" | "file" | "symlink"
      readonly differences: readonly (
        "uid" | "gid" | "mode" | "atimeNs" | "mtimeNs" | "ctimeNs" | "birthtimeNs" | "content"
      )[]
    }
  | {
      readonly _tag: "Updated"
      readonly path: BytePath
      readonly kind: "directory" | "file" | "symlink"
      readonly differences: readonly (
        "uid" | "gid" | "mode" | "atimeNs" | "mtimeNs" | "ctimeNs" | "birthtimeNs" | "content"
      )[]
    }
```

Added in v0.6.0
