# Caller overview

Caller identity brands and schemas: credentials, root caller options, and
the settings and results of the operations a caller performs.

Added in v0.6.0

---

## models

### DirectoryChange (type alias)

A directory's revision before and after a change.

**Signature**

```ts
export type DirectoryChange = { readonly before: bigint; readonly after: bigint }
```

Added in v0.6.0

### Identity (type alias)

A caller's credentials.

**Signature**

```ts
export type Identity = {
  readonly uid: number
  readonly gid: number
  readonly groups: readonly number[]
  readonly privileged: boolean
}
```

Added in v0.6.0

### MkdirReferenceSettings (type alias)

Settings of a reference-addressed directory creation.

**Signature**

```ts
export type MkdirReferenceSettings = {
  readonly mode?: number
  readonly exactMode?: boolean
  readonly times?: {
    readonly access:
      | { readonly kind: "now" }
      | { readonly kind: "omit" }
      | { readonly kind: "value"; readonly nanoseconds: bigint }
    readonly modification:
      | { readonly kind: "now" }
      | { readonly kind: "omit" }
      | { readonly kind: "value"; readonly nanoseconds: bigint }
  }
}
```

Added in v0.6.0

### OpenChildReferenceSettings (type alias)

Settings of a lookup-or-create-and-open through a parent reference.

**Signature**

```ts
export type OpenChildReferenceSettings = {
  readonly access: "read" | "write" | "readWrite"
  readonly mode?: number
  readonly create?: "never" | "ifMissing" | "exclusive"
  readonly append?: boolean
  readonly truncate?: boolean
  readonly followFinalSymlink?: boolean
  readonly exactMode?: boolean
  readonly times?: {
    readonly access:
      | { readonly kind: "now" }
      | { readonly kind: "omit" }
      | { readonly kind: "value"; readonly nanoseconds: bigint }
    readonly modification:
      | { readonly kind: "now" }
      | { readonly kind: "omit" }
      | { readonly kind: "value"; readonly nanoseconds: bigint }
  }
  readonly initialSize?: bigint
  readonly owner?: { readonly uid?: number; readonly gid?: number }
  readonly expectedChild?: {
    readonly reference: ObjectReference
    readonly revision: bigint
    readonly atimeNs: bigint
    readonly mtimeNs: bigint
  } | null
}
```

Added in v0.6.0

## schemas

### DirectoryChange

Schema for a directory's revision before and after a change.

**Signature**

```ts
export declare const DirectoryChange: Schema.Struct<{ readonly before: Schema.BigInt; readonly after: Schema.BigInt }>
```

Added in v0.6.0

### Identity

Schema for a caller's credentials. `privileged` is explicit; uid zero alone
grants nothing.

**Signature**

```ts
export declare const Identity: Schema.Struct<{
  readonly uid: Schema.Natural
  readonly gid: Schema.Natural
  readonly groups: Schema.$Array<Schema.Natural>
  readonly privileged: Schema.Boolean
}>
```

Added in v0.6.0

### MkdirReferenceSettings

**Signature**

```ts
export declare const MkdirReferenceSettings: Schema.Struct<{
  readonly mode: Schema.optionalKey<Schema.Natural>
  readonly exactMode: Schema.optionalKey<Schema.Boolean>

      readonly access: Schema.Union<

          Schema.Struct<{ readonly kind: Schema.Literal<"omit"> }>,
          Schema.Struct<{ readonly kind: Schema.Literal<"value">; readonly nanoseconds: Schema.BigInt }>
        ]
      >
      readonly modification: Schema.Union<
        readonly [
          Schema.Struct<{ readonly kind: Schema.Literal<"now"> }>,
          Schema.Struct<{ readonly kind: Schema.Literal<"omit"> }>,
          Schema.Struct<{ readonly kind: Schema.Literal<"value">; readonly nanoseconds: Schema.BigInt }>
        ]
      >
    }>
  >
}>
```

Added in v0.6.0
