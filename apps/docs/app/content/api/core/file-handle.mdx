# FileHandle overview

Identity brands and schemas for open file and directory handles.

Added in v0.6.0

---

## models

### SeekMode (type alias)

The origin of a seek.

**Signature**

```ts
export type SeekMode = "start" | "current" | "end" | "data" | "hole"
```

Added in v0.6.0

## schemas

### SeekMode

Schema for the origin of a seek: the file start, the current position, the
end, or the next data or hole region.

**Signature**

```ts
export declare const SeekMode: Schema.Literals<readonly ["start", "current", "end", "data", "hole"]>
```

Added in v0.6.0
