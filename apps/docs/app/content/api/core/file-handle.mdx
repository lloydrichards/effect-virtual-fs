## schemas

### SeekMode

Schema for the origin of a seek: the file start, the current position, the
end, or the next data or hole region.

**Signature**

```ts
declare const SeekMode: Schema.Literals<readonly ["start", "current", "end", "data", "hole"]>
```

[Source](https://github.com/lloydrichards/effect-virtual-fs/blob/main/packages/core/src/FileHandle.ts#L47)
