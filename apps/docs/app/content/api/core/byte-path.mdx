# BytePath overview

---

## models

### BytePath (interface)

An opaque path that preserves arbitrary non-NUL bytes without UTF-8 conversion.

**Signature**

```ts
export interface BytePath extends Equal.Equal, Pipeable {
  readonly [BytePathId]: BytePathId;
}
```

Added in v0.1.0
